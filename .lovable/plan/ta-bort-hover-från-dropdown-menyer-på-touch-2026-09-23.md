# Ta bort hover från dropdown-menyer på touch

## Ändring
- Stoppa dropdown-alternativ från att automatiskt markera första raden när menyn öppnas med touch.
- Behåll tangentbordsmarkering för dator och riktig hover för mus/pekplatta.
- Lägg ett gemensamt touch-skydd på jobbskapande, jobbredigering och delade dropdown-menyer så att hover inte kan fastna efter tryck.

## Verifiering
- Kontrollera öppna menyer på mobil/touch i skapa och redigera jobb.
- Säkerställ att mus-hover och tangentbordsnavigering fortfarande fungerar på dator.
- Kör typkontroll och relevanta tester.
